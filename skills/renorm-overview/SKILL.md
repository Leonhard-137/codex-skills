# Renorm Overview：重整化迭代法

用可理解的概念块构成连贯概述，再随学习逐步展开。这里的“重整化”是知识组织的比喻，不是物理重整化方法。单独调用即可开始，不要求先创建项目或读取 study。

## 每次概述都遵守

- 沿用用户已明确的目的、基础、时间预算和展开尺度；缺失信息确实影响内容时才简短补问。用户控制范围、深入方向和停止，不限制问答轮数。
- 默认当前对话 agent 兼任内容与机械整理；用户指定时才分开。第一次概述先在对话中呈现，只有用户要求或已有保存约定才写文件。
- 用户 MD 只能直接作含义明确的机械修正，不能改句子、论点或推导；概念问题在对话中指出，由用户改。只有明确委托 AI 写的段落才可写入，并标 `AI写` 与来源；概要 MD 用 `概要型` 标记，混合内容分清作者。
- 不把打包内容当作已经掌握；不靠隐瞒关键条件让概述显得简单，也不因补一个前置就自动开启整门课。

## 1. 先确定这次要看清什么

从已有上下文提取：本轮要理解的对象/问题、希望达到的效果、已有基础、暂不展开的内容。新学习任务须遵守 [study 的启动确认](../study/SKILL.md#学习启动前确认)：先判断尺度与方向，简短说明并向用户确认，收到确认后才开始本方法的资料调研与概述。单独调用本 Skill 也适用；study 或当前任务已经完成确认时直接沿用，局部追问和继续展开不重复确认。不强制填写模板。

有明确用途的小主题，采用可检查目标，例如“说明 DRW 是什么，并写出生成曲线的伪代码”。面向长期的大领域，先确定用途与重点，不假装一次概述能验收长期能力。指定论文/书籍时，以理解原资料为目标，不能用 AI 概述替代后续阅读。

## 2. 优先找适合读者的材料

检查已有来源及相关笔记，按需检索可信教材、课程、论文或作者文档。实际阅读相关内容后判断覆盖范围、前置、组织方式和深度；标题/摘要只能支持相应层次的判断。

有合适概述，给出实际阅读位置和它能提供的方向，直接用原文；必要时补其与当前目标的关系。没有合适概述，才综合来源写本轮概述。不要将找到的资料全列成阅读清单，也不要要求找到一本完全契合的书才能开始。

普通外部检索使用原生能力。仅用户点名或 web-access 已确认能力缺口并路由时调用 uni-search；本地笔记/PDF 按需要用 OVN/MPK。可选工具缺失时如实限定来源覆盖，不自动安装或全库扫描。

## 3. 在一个尺度上组织文章

默认写可连续阅读的短文章，沿着当前主题的问题组织段落；列表按需辅助。结构、关系或过程适合直观理解时，按 [图片与可视化讲解](../study/SKILL.md#图片与可视化讲解) 主动配图，图文共同说明当前尺度的概念。说明每个主要部分是什么、核心问题是什么、为什么在此出现、与其他部分怎样相接。复合标题中的名词也要交代关系，不能只解释其中一个。

将内部推导、算法和分支打包，交代概念块的作用、必要输入/输出或成立条件；它们是组织工具，不强迫每块使用同一模板。并列、包含、工具和应用关系如实表达，不能为连贯而捏造推导链。

只展开帮助当前读者建立联系的少量关键细节。读者尚不认识的标签不能代替解释；后文不得依赖一个尚未解释却被当作已知的细节。公式仅在当前尺度有作用时出现，并说明对象和含义，不自动追溯所有数学基础。

文章独立成文，不把“你刚才要求”“这解释了为什么这两章放一起”等提示词协商写进正文。来源标在支持的主张附近；区分原作者、补充材料与 AI 为教学组织的解释，不把综合出来的分类说成文献唯一标准。

两种常见范围：
- **论文：** 研究什么、为何重要 → 方法与分析怎样回答问题 → 结果、解释及限制。依据实际原文，无法读取的部分明确限定。
- **教材/领域：** 用中心问题连接主要部分及前置关系。以课程/教材作长期骨架，不在概述中同时展开每个子领域。

## 4. 用两个判断决定是否继续打包

1. **当前层能否理解：** 凭用户已有基础和本轮解释，能否辨认这些概念块及其联系？若只剩生词标签或关键前提缺失，就换更具体的图景或补最小桥梁，不能只让用户接受黑箱。
2. **是否足以指导下一步：** 用户能否知道下一步学什么、为什么学，以及它对目标的作用？能则停止扩展当前概述；不能则补缺失的关系或调整粒度，不默认展开所有细节。

这是写作与讨论的判断依据，不是必须让用户通过的考试。交付前自查关系是否清楚，用户觉得不清楚时据实际断点修订。

## 5. 随用户选择迭代

用户写概要、提问或选择一个概念块 → 在选定范围解释/阅读 → 以 feyn-review 讨论其表述 → 用获得的理解回看概述。每轮可以修正组织与目标，但用户追问一个局部问题，不等于授权扩大学习项目。

概要里的不精确表述要按影响处理：会改变主要结论、因果关系或造成逻辑矛盾的错误，立即简短指出；不影响当前图景的技术细节/次要条件，只在对话或已有待核实位置标明具体问题及以后查哪里，不展开证明，也不说它已正确。用户明确追问后再展开，仍不改写用户原句。

下探到已有合适章节/文章的层次，就让用户读原资料并转入局部问答，不为继续迭代而坚持由 AI 从头讲完。缺口需要新的学习链时，说明它与当前目标的关系，用户决定是否纳入。

当前概述足以给出方向即交付，等待用户选择。用户决定组织讲义时，由 study 协调其自己的整体表述、序言和目录；不自动编写 Small/Big Topic 正文。真实 Vault 编辑使用 OVN 的学习草稿规则；具体资源管理方法交由 MPK，不能伪称已保存或已索引。
