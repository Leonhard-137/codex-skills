# 五种学习情境

只读当前情境。所有情境沿用 study 的文字保护、用户控制深度、来源归属和默认同 agent 约定。

## 1. 知识点学习

用户提出局部问题或指出阅读中的断点 → 按当前所需深度解释 → 用户选择是否写自己的理解 → feyn-review 读取当前笔记、静默修正机械错误、指出内容问题、回答本轮问题 → 用户修改，如此循环。

没有 MD 也可以先问、先读。只需初步接触的内容，用户可委托 AI 留下一条带来源和 `AI写` 标记的记录，不必强迫自己长篇重述。用户判断何时足够；新知识点是否另建文件/对话也由用户决定。

产物可以是一条笔记、已有笔记的更新或仅完成当前答疑，不自动形成 Small Topic。

## 2. 思维链尺度：整体到局部

### 有指定资料：论文、教材章节或其他原材料

1. 从明确的资料与阅读目的开始。核对版本并阅读足以支撑初始概述的原文；教材先看相关目录、引言和所选单元。论文概述覆盖研究问题及重要性、方法、分析过程、结果与讨论。只读到摘要时如实限定，不称已阅读全文。
2. 第一次引子和概述先在对话中呈现。按 renorm-overview 保持整体尺度，用户用自己的概要 MD 整理并提出问题；沿用已有读者基础，必要时才补问。
3. 用户开始读原材料后，直接支持逐段阅读和局部答疑；不要求先由 AI 重写讲义。具体知识点可进入情境 1，概要 MD 留主线、打包概念和链接。
4. 用户认为读完一篇论文、一个章节或积累足够理解，并要求整理时，进入情境 3。读完不是自动写讲义、测验或判定掌握的触发器。

用户计划读完指定资料时，保留这一目标；对话中的摘要不能代替原文。用户后来改变范围则沿用新决定。

### 无指定资料，但有明确用途

1. 用已有上下文与必要的简短交流确定最终效果、重点和已知基础；如果有时间预算也沿用，不凭空设学习时限。
2. 检索并实际检查候选资料。合适的章节/文章可直接充当骨架；没有合适材料时，用 renorm-overview 将必要知识打包，先交付可理解的局部概述与学习方向。
3. 用户选择展开哪一块。AI 说明该块对目标的作用，在当前尺度解释，用户以 feyn-review 迭代笔记。背景不足时先补最小必要桥梁；若已经需要一条新的学习链，说明缺口，让用户决定是否扩大范围。
4. 用户觉得原定效果已足够，可以结束；只有用户需要连贯讲义才进入情境 3。目的明确的小主题不要求先学完整个上位领域。

## 3. 思维链尺度：局部到整体

1. 两种入口：用户提出已形成的联系；或用户请 AI 从已有笔记中寻找候选联系。后一种通过 OVN 做有边界、可跨学科的检索，读命中笔记的实际内容，再提出少量有依据的主线与尚缺的环节。相似词或反向链接不等于逻辑联系，不默认全库通读。
2. 用户说明整体理解、想表达的主线与重要细节。AI 据此检查逻辑、来源与遗漏，在对话中建议组织方式；不替用户改写原稿。需要新知识或推导时返回情境 1/2，补齐当前缺口即可。
3. 用户逐轮修订，形成最终序言与各节安排。序言说明为什么写、主要问题与论证如何推进；目录来自这条主线，不先套固定章数。沿用已有概要 MD，不另造入口或地图文件。
4. 用户逐节在 MD 中写内容；按 feyn-review 做机械整理与讨论。整合建议、替代表达只在用户要求时给出，仍由用户决定并亲自形成其理解的表述。
5. 用户确认内容后，按其要求交给 textbook 转为 Small Topic 的 TeX 工程；保留段落、命题和推导次序，仅作机械与排版处理。若还有需要判断含义的问题，返回当前讨论，不在排版中猜写。

概要 MD 被正式讲义替代时：先完成用户要求的输出核查，将有效内容、来源、待解决问题和入链迁入新载体；用户明确采用替代方案后，或沿用已确认的删除安排，再通过 OVN 删除旧概要。保留知识点 MD。不能仅因生成了 TeX 就删掉唯一可用草稿；也不默认额外保存一份同内容入口。

## 4. 知识网络尺度：整体到局部

1. 明确长期方向与当前基础，辨认个性化侧重。例如 AI 可以侧重科研应用、工程经验和人机协作；这些目的不直接构成穷尽所有章节的清单。
2. 调研适合当前读者的高质量课程/教材，实际检查目录和代表性内容，说明主线、前置与适用深度。优先选能提供系统骨架的资料，必要时用少量补充来源覆盖缺口。
3. 现成概述足够好就用原文。否则按 renorm-overview 打包主要领域，说明各部分是什么、解决什么问题、互相如何联系；不在一篇概述里展开所有章节。
4. 在已有初步认识上与用户调整范围、顺序和重点。选定一个单元后复用情境 2，再对局部使用情境 1；用户读原资料，AI 补充断点。全领域逐点问答不是唯一默认学习方式。
5. 学到局部后可回看概要修正理解，但不强制每轮重写地图。用户希望组织自己的系统讲义时进入情境 5。

## 5. 知识网络尺度：局部到整体

用户已有多条思维链，或想用已掌握的知识编写教材，均可进入；不要求先积累固定数量的 MD/Small Topic。

沿用情境 3 的组织方法：用户说明全书主线 → 按实际需要检索知识点与已有文章 → 检查重复、差异、缺口与章节关系 → 共同确定序言和目录 → 用户逐章组织内容 → 确认后由 textbook 排版。

同一知识点可以进入多条思维链；复用须核对语境、假设和符号，不能把独立讲义直接拼接成教材。发现知识缺口再局部补学，不因编写全书而预先写完所有前置。正式工程归 Big Topic；关联的知识点与独立 Small Topic 不因被引用就删除。

## 保存与交接时才需要的约定

- **位置：** 从已有项目、用户明确指定的位置及 MPK/OVN 本机配置确定实际 Knowledge/Vault。一种可选布局是在知识根内使用 `笔记库/学习/MD`、`笔记库/学习/Small Topic`、`笔记库/学习/Big Topic`；后两者保存完整工程。PDF 资料库用实际配置的位置。通用 Skill 不写死盘符，不迁移旧项目；沿用使用者已有或明确指定的目录。
- **笔记：** 原子 MD 尽量围绕一个可复用问题、概念或关系，允许必要前置和覆盖重叠；概要 MD 只保留主线、打包内容和链接。标题变大不强制拆分，真正拆分/合并由用户决定。
- **标记：** `概要型` 表示用途，`手写`/`AI写` 表示作者，可组合；混合内容在段落标明归属，不把整篇误标为单一作者。保留已有标签，不为整齐而批量重标。草稿、已读、待核实不是掌握认证。
- **来源：** 将支持具体主张的来源标到相应段落，保留作者/题名、版本、章节/公式/页码或稳定 URL 中实际可得的信息；只搜索到的文献不能算已核对。外部解释、原作者结论、用户猜想分清。
- **PDF：** 已授权保存参考资料时，先查资料库是否已有，合法可下载的全文存入既有分类；无全文时保留可访问链接和缺口，不编造本地路径。通过 MPK/OVN 维护实际支持的资源链接及页码，不能把资源 ID 或索引命中当作科学结论。
- **自编讲义：** 用户选定的正式 PDF 可按既定安排复制到资料库供 MPK 检索，更新同一发布副本；主工程仍是编辑来源。无用户选择/既定发布安排时，不把每次临时编译都复制入库，不自动全库重建索引。
- **跨 Skill：** 交接只需已有原稿路径、确认范围、主线、实际来源、输出要求和未解决事项；在当前对话传递即可，不强制生成交接文件。排版或展示完成不等于用户已理解内容。
