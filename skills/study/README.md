# Study：用户主导的学习工作流

这份 README 给使用者阅读，解释设计与使用方式。Agent 的执行入口是 SKILL.md，不需要在每轮答疑前重读本文。

## 设计目的：1323

**1 条主线：为接下来的学习提供方向。** 学习已有知识时，优先借助合适的教材、课程与论文；AI 帮助查找材料、说明问题与联系、补齐当前所需的推导和前置。避免在不知道整体问题的情况下，从一个新名词不断追到另一个新名词。

**3 个知识尺度：知识点、思维链、知识网络。** 一个知识点可以被多条思维链使用，多条链又能形成不同的网络。MD、Small Topic、Big Topic 是常用载体，并非严格对应：一个 MD 可以是局部理解，也可以是打包内容的概要。每个尺度的进步都可能反过来改变其他尺度，不是一条固定升级路线。

**2 个方向：局部到整体、整体到局部。** 前者从已形成的理解寻找联系并组织文章；后者先认识主题与方向，再学习其中的部分。两者可以在一次学习中交替。

**3 个能力维度：整体认识、细节掌握、应用与创新。** 它们并行发展。能清楚重述不等于能独立应用，能计算也不等于清楚自己在解决什么问题；产物的完成不能替代能力证据。

这套学习流程面向已有知识。科研假说、工具故障与缺少系统资料的未知问题探索，另由后续探索工作流承担；探索中的局部补学仍可以接入这里。

## 两个方法怎样组合

- **feyn-review：重述、反馈与改进。** 问/读 → 用自己的理解写笔记 → AI 机械整理、指出理解错误并回答问题 → 自己修改 → 继续。理解通过可见的个人表述逐步改善。没有必要重述的浅层接触可以只读，或委托 AI 留一条带来源的记录。
- **renorm-overview：重整化迭代。** 在约定尺度将细节打包，先理解主要部分是什么、核心问题是什么、彼此怎样联系；再选择一块展开，并回看整体。打包后必须仍能理解，也必须有助于判断下一步。当出现合适的现成材料，就转为阅读材料与局部问答。

这里的“重整化”仅是组织知识的比喻。它不是要求 AI 一次掌握全领域，也不是让学习者沿着无限前置链摸索。

## 五种使用情境

| 情境 | 使用方式 |
| --- | --- |
| 知识点 | 用 feyn-review 问清当前问题，需要时写原子 MD。 |
| 思维链，从整体到局部 | 先用概述认识论文/教材单元，或明确小主题的用途；再读原材料、补局部知识。 |
| 思维链，从局部到整体 | 自己发现联系，或让 AI 从笔记提出候选；自己说明主线，经讨论形成序言、目录，再逐节写 Small Topic。 |
| 知识网络，从整体到局部 | 选高质量课程/教材作骨架，按自己的目的调整重点；逐个单元复用前面的学习方式。 |
| 知识网络，从局部到整体 | 从积累的理解或已有知识组织全书，先定主线、序言和目录，再逐章写 Big Topic。 |

有指定资料时，先读原资料。AI 初始引子与概述在对话里给出，不默认另写一本替代讲义。论文引子说明问题及重要性、方法、分析、结果与讨论；读完一篇或一章后，由你决定是否把理解整理成自己的文章。

## 人和 AI 各做什么

你决定目的、范围、深入程度、笔记划分与何时整理；真正需要重新思考的内容，由你形成文字、关键推理和判断。AI 负责检索、局部解释、核查错误、机械修正与明确委托的制作工作。

默认一个对话 agent 兼任内容与排版。需要分工时由你指定：内容在 MD 中讨论确认，排版方接收确认稿；排版工作不获得另写内容的许可。进入 Small/Big Topic 后仍可在 MD 写作，确认后才交给 textbook 转换为 TeX。

用户句子即使不够漂亮也应保留。笔误、标点和含义明确的公式语法可以静默修正；改变命题、推理、措辞与组织方式需要内容讨论。措辞建议默认关闭，询问时只在对话中给出，由你决定如何重新表达。AI 明确指出错误不等于它可以替你改掉原句。

显式委托 AI 写参考内容是允许的，要标 `AI写` 和实际来源。`手写` 表示你的表述；`概要型` 表示笔记用途，二者可组合。混合笔记按段落标明归属。机械整理不改变作者身份。

## MD、讲义与资料的组织

日常 MD 尽量围绕一个可复用的知识点、问题或关系，但不要求脱离所有前置就能独立理解。内容重叠、未完成推导和暂未理顺的联系可以存在。概要 MD 存主线、打包概念和链接，具体知识点逐步另记；拆分由你决定，不为标题大小而强制重构。

一种可选布局是在知识根下使用 `笔记库/学习/MD`、`笔记库/学习/Small Topic`、`笔记库/学习/Big Topic`，后两者包含完整工程。实际路径沿用使用者的 MPK/OVN 配置、已有项目或明确指定的位置，Skill 不绑定 Windows 盘符；课程、标签和链接可跨学科，不重建学科文件夹入口体系。

概要被正式讲义替代后，迁移有效内容、来源及相关入链，按你采用的替代安排删去旧概要；知识点笔记继续保留。Big Topic 使用某条链时，不要求删除独立 Small Topic。

OVN 负责实际 MD 的检索、受限修改与链接，MPK 负责 PDF、资源身份和索引。需要保存的参考 PDF 先查重，再按既有资料库组织存放，段落保留可追溯的位置。网页等没有 PDF 的来源保留可用链接，不制造虚假本地附件。自编讲义的正式 PDF 可按约定复制入库供检索，编辑来源仍是原工程。

其他 Skill 按需协作：textbook 负责已确认内容的 TeX 输出；paper-to-talk 与 beamer 在明确要求时制作展示材料；uni-search 遵守自身的进入条件，常规检索先用原生能力。这里没有默认跨 Skill 的整套执行清单。

## 给学习者的建议，不作为强制闯关

- 开始有明确用途的小主题前，可在纸上写下目标和验收标准。察觉发散时，询问当前内容对目标的作用，再决定继续还是收束；不要依赖 AI 永不遗漏主线。
- 自拟笔记时暂时不看对话，尝试从理解中重新生成，写完再核对。不是每个刚见过的概念都值得长篇重述。
- 关键推导建议自己走一遍，并代入实际数字检查；TeX 语法、重复计算和排版可交给 AI。哪些部分值得自己动手，由你按学习目的判断。
- 过几天回看旧问题或在新情境重新解释，可以检查是否保留了理解；连续几天读同一篇文章，并不自动等同于对同一内容做间隔提取。这里不强制计划或自动发送提醒。
- 来源最好在学习时顺手留下：现在只需粗浅认识的内容，可以标待核实；后来形成正式讲义时更容易核对版本、假设和引用。
- 学习已有知识也可能遇到 AI 错误。默认按主张的重要程度核查原文、关键推理或小计算，不强制多个 AI 相互审稿；不要把语言流畅或模型更新当成正确性的证据。

## 练习：有价值，但仍是设计缺口

练习可能用于检验理解、训练迁移、提高熟练度以释放注意力。这三种目的并非每次都需要同时实现；偶发计算失误也不自动否定正确思路，生涩感是否值得消除取决于后续用途。

当前尚未解决的是：在 AI 能代做大量工作、练习启动成本又高的情况下，怎样让人愿意做真正有益的练习。因此本版不自动出章末题，不强制编程、口试或间隔复习。你明确要求练习或采用练习计划时，再按其目的选择任务与帮助程度；看懂 AI 的解答不记为独立完成。

## 如何使用和检查本版

三个目录 `study`、`feyn-review`、`renorm-overview` 可并列安装到本机发现 Skill 的目录。study 组合两个方法；两个方法也能单独调用，关键文字保护不依赖先读取 study。OVN/MPK 等是按任务需要使用的能力，未安装时必须说明具体缺口，不能宣称已执行其校验或索引。`agents/openai.yaml` 只是入口显示配置，不会启动新 agent。

本版以新方法替代旧 teach-me；其来源核查和重述诊断思想得到保留，旧版还记录过上游 [MehdiJenab/my-skills](https://github.com/MehdiJenab/my-skills)。旧整章先写、自动重编、课程课时与自动练习规则不作为本版默认。已有学习项目不会因 Skill 更新被重排或改写。

学习入口与两个方法已接入 textbook 和展示流程：确认 MD 可按指定范围转换为 Small/Big Topic 讲义，也可以直接作为展示材料，不要求先有讲义 PDF。textbook 默认保留原文做机械转换；明确委托制作 slides/报告时，可以在派生产物中摘要、翻译与组织叙事，但不反向改写你的笔记。各类输出按你选定的范围制作，不自动配齐讲义、报告、问答和演练。

格式校验只证明 Skill 文件结构合规。更有用的试用是：含笔误和理解错误的手写 MD 是否被保留；概述能否在约定尺度上串起关系；只问局部问题是否会误启动整套流程；多轮以后这些边界是否仍有效。需要实际观察，不能从规则写得完整推定必然执行。
